# Schritt 85b — Feinschliff der Oberfläche

- **Ziel:** Die Oberfläche wird ruhiger und lebendiger, **ohne** Layout zu
  verschieben: Karten reagieren auf den Zeiger, der Fokus ist überall sichtbar,
  die Schiene zeigt den aktiven Ort mit einem Balken, und unten in der Schiene
  sitzt ein kleiner Begleiter, der blinzelt und auf „fertig“/Fehler reagiert.
  Alles nur über CSS-Klassen und Token; keine neuen Farben, keine neuen Texte.

- **Eingang:**
  - `client.js`: `AKZENT_STIL` (um 1876–1886, wird als `<style>` eingehängt),
    Board-Wurzel mit `data-board-akzent` (um 10164), `S.karte` (680),
    `S.schienenKnopf`/`S.schienenKnopfAktiv` (530–545), `S.schiene` (528),
    `S.page` (180), Kartenhülle (um 7900), `schienenKnopf` (um 8750),
    `status` (`{ art, text }`).
  - `arbeit/feinschliff.md` — Regeln und Reihenfolge.

- **Tun:**
  1. **Wurzel benennen.** Die Board-Seite bekommt `className: 'board-seite'`
     (neben `data-board-akzent`). Alle neuen Regeln stehen unter
     `.board-seite …`, damit das Dashboard unberührt bleibt.
  2. **Karten.** Die Kartenhülle bekommt `className: 'board-karte'` (aktive
     Karte zusätzlich `board-karte-aktiv`). CSS:
     `.board-karte { transition: filter .14s ease; }`
     `.board-karte:hover { filter: brightness(1.04); }`
     `.board-karte:focus-visible { outline: 2px solid var(--board-akzent); outline-offset: 2px; }`
     Kein `transform` (die Verbindungen rechnen mit den Kartenkanten).
  3. **Fokus überall.** `.board-seite :is(button, input, textarea, select, [tabindex]):focus-visible`
     bekommt `outline: 2px solid var(--board-akzent); outline-offset: 2px;`.
     Keine `outline: none`-Regel.
  4. **Schiene.** `schienenKnopf` bekommt `className: 'board-schiene-knopf'`.
     CSS: `position: relative`; bei `[aria-pressed="true"]` ein 2-px-Balken
     links in `var(--board-akzent)` über `::before`; beim Überfahren wird die
     Beschriftung `var(--dsw-alias-label-primary)` (der Span erbt die Farbe).
  5. **Begleiter.** Unten in der Schiene (`marginTop: 'auto'`, zentriert,
     `pointer-events: 'none'`, `aria-hidden: 'true'`) sitzt eine kleine SVG-
     Figur (18 × 18): Kopf, zwei Augen, Mund. `data-art` kommt aus
     `status.art` (`fertig`, `fehler`, sonst `ruhe`); der Mund wechselt
     (Lächeln / kleines „!“ / Strich). CSS lässt die Augen alle ~6 s blinzeln
     (`@keyframes board-blinz`), ohne Text und ohne Klickziel. Kein neuer
     Schlüssel.
  6. **Bewegung achten.** `@media (prefers-reduced-motion: reduce)` schaltet
     Übergänge und Animationen unter `.board-seite` ab.
  7. **Nicht:** Abstände, Schriftgrößen, Breiten, Höhen, Reihenfolge oder
     Positionen ändern; keine harten Farben (nur `var(--dsw-…)` und
     `--board-akzent`); keine neuen sichtbaren Texte.

- **Ergebnis:** `client.js` mit den Klassen und dem Stilblock;
  `test/nach85b.mjs`; Bericht.

- **Prüfung:**
  - `cd /workspace/projekte/board-plugin && node --check client.js && node --test test/*.mjs`
  - `test/nach85b.mjs`:
    1. `AKZENT_STIL` enthält die Regeln für `.board-karte:hover`,
       `:focus-visible`, `.board-schiene-knopf[aria-pressed="true"]::before`,
       `.board-begleiter` und `prefers-reduced-motion`;
    2. die Wurzel trägt `className: 'board-seite'`, die Karten
       `className: 'board-karte'`, die Schienenknöpfe
       `className: 'board-schiene-knopf'`;
    3. der Begleiter ist `aria-hidden`, `pointer-events: none`, ohne Text;
    4. keine Regel setzt `outline: none`; keine Farbe außerhalb
       `var(--dsw-…)`/`var(--board-akzent)`;
    5. kein Layoutwert in `S.page`/`S.koerper`/`S.karte`/`S.schiene` hat sich
       geändert (Vergleich der Blöcke gegen den Stand davor — als
       Zeichenkettenprüfung auf die vorhandenen Maße);
    6. Schlüsselzahl 614.
  - Gegenproben: `prefers-reduced-motion` entfernen → rot; `outline: none`
    einsetzen → rot; `className: 'board-seite'` entfernen → rot; Begleiter
    ohne `aria-hidden` → rot.
  - Sichtprüfung im Browser macht er in Schritt 86.
