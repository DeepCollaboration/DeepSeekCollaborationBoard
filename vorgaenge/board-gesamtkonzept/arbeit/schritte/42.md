# Schritt 42 — Der Umzug als Route

- **Ziel:** Der Umzug läuft aus dem Board, mit Zuordnung der Kennungen zu GitHub-Namen; die alte Ablage bleibt unverändert.
- **Eingang:** `werkzeuge/umzug2.mjs`; `identitaet.json`; `index.js` (Board-Routen); `test/markt41.mjs`.
- **Tun:**
  1. **Route.** `POST /board/umzug` mit `{ zuordnung?, ziel? }`; ohne Zuordnung wird die vorhandene Kennung-zu-Name-Abbildung verwendet (aus `identitaet.json` bzw. dem Register), und die Antwort nennt sie vor dem Lauf.
  2. **Lauf.** Der vorhandene Umzug (`werkzeuge/umzug2.mjs`) wird dahintergelegt, auf dem genannten Ziel (Vorgabe: ein neuer Ordner unter `$DSH_HOME/board/umzug`); die alte Ablage wird nur gelesen.
  3. **Bericht.** Die Antwort nennt je Repository: Name, GitHub-Name, Sichtbarkeit, angelegt/übersprungen, Fehler; die Zuordnung steht im Bericht.
  4. **Stopp.** Ohne Schreibrecht 403; ohne Ziel 400; ein zweiter Lauf auf dasselbe Ziel überschreibt nichts, sondern nennt die vorhandenen.
  5. **Prüfung.** `test/markt42.mjs`: auf einer Kopie der alten Ablage; Aufruf schreibt die Repositories, der Bericht nennt die Zuordnung, die alte Ablage ist danach byte-gleich (Prüfsumme), ein zweiter Lauf ändert nichts.
- **Ergebnis:** Umzug als Route mit Zuordnung und Bericht; alte Ablage unberührt; `test/markt42.mjs` grün.
- **Prüfung:** `cd /workspace/projekte/board-plugin && node --test test/markt42.mjs` → `ok Umzug: Route, Zuordnung, alte Ablage unverändert`; danach `node --test` → 57 vorhandene plus der neue Test, 0 Fehler; `node --check index.js` → 0.
- **Grenzen:** Produktordner und `test/markt42.mjs`; kein Netz; keine Rückfrage; keine eigenen Commits.
