# Schritt 73 — Entwicklerdoku im Repo

- **Ziel:** Ein Fremder findet im Repository Route, Datenformat, Ablage und
  Prüfung, ohne den Code zu lesen. Vier Dokumente unter `docs/`, auf Deutsch,
  mit Verweisen auf die Dateien.

- **Eingang:** `index.js` (Routen, Ablage, Rechte), `formate/{station,workflow,
  vorhaben,board}.js` (Felder, Fassungen), `client.js` (Aufbau, Slots,
  Übersetzung), `boards.js`/`ablage.js` (Register, Speicherorte),
  `github.js` (Token, API), `werkzeuge/` (Abnahme, Prüffläche), `package.json`.

- **Tun:**
  1. `docs/architektur.md` — was das Plugin ist; Host und Client; wo Daten
     liegen (`$DSH_HOME/board`, Git-Repositories); kein Dienst, keine
     Datenbank, keine eigene Anmeldung; GitHub als Zugang und Recht; wie ein
     Board aus Repositories zusammengesetzt wird; Slots und Übersetzung;
     Prüfungen und ihre Grenzen (kein Browser, Werkstatt-Tests).
  2. `docs/entwicklung.md` — Voraussetzungen (Node 24, DSH), einklinken ins
     Profil, starten/neu laden, `npm test` (lokal 83, CI 49), `npm run check`,
     Aufbau von `client.js` (Stilblock, Abschnitte, Bausteine), Regeln (Token,
     Schrift 12/13/14/18/22, Radien 6/8/12/999/50 %), **eine Sprache
     hinzufügen** (Wörterbuch, `addLanguage`-Liste, 614 Schlüssel, Tests,
     Platzhalter), Fehlersuche (`/board/data`, `/board/sprache`, Server-Log,
     `test/schritt30`-Flake).
  3. `docs/datenformate.md` — je Format die Ankerdatei, Fassung 1 und 2, die
     Felder mit Typ und Bedeutung, ein kleines Beispiel, Verweise als
     `owner/repo`, `sichtbarkeit.json`, was fehlen darf.
  4. `docs/routen.md` — Tabelle aller `/board/*`-Routen aus `index.js`:
     Methode, Pfad, Zweck, Recht/Voraussetzung, Antwort; Fehlercodes
     (400/403/404/409/502) und was sie bedeuten; der Weg Token → Prüfung →
     Schreiben.
- **Ergebnis:** `docs/architektur.md`, `docs/entwicklung.md`,
  `docs/datenformate.md`, `docs/routen.md`.
- **Prüfung:** Jede Route der Tabelle kommt in `index.js` vor und umgekehrt;
  jedes Feld der Formate kommt im Leser vor; die Sprach-Anleitung führt in
  unter einer Stunde zu einem weiteren Wörterbuch (Stichprobe); keine erfundenen
  Funktionen; relative Links funktionieren.
- **Grenzen:** Nur `docs/`. Kein Code, keine Tests, keine Commits.
