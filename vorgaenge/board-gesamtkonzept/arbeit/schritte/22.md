# Schritt 22 — Die frische Installation

- **Ziel:** Eine neue Installation erlebt das Board ohne Einrichten: Hauptboard, Stationen, Probeprojekt, Lesen; erst beim Beitreten kommt der eigene Name, dann das eigene Board; der Token bleibt optional.
- **Eingang:** Schritt 21; `README.md`; `package.json`; `erststart.js`; `client.js`.
- **Tun:**
  1. Schreibe `README.md` neu für die Fassung 2: was das Board ist (Stationen, Workflows, Vorhaben, Boards als Repositories), installieren im DSH-Profil, erster Start (Hauptboard kommt von selbst), lesen ohne Namen, eigenes Board über das Probeprojekt, GitHub-Token optional (was er kann, wo er liegt), wie ein Beitrag/Fork/Frage läuft, wo die lokalen Dateien liegen. Keine alten Befehle, die es nicht mehr gibt; keine Platzhalter.
  2. `package.json`: `files` um `github.js`, `katalog.js`, `rechte.js`, `erststart.js`, `werkzeuge/` ergänzen; `description` und `version` bleiben, wenn nichts Besseres belegt ist.
  3. `test/schritt39.mjs`: eigenes Home ohne `boards.json` und ohne `identitaet.json`, lokales Bare-Repository als `DSH_BOARD_HAUPTBOARD`, Server in-process. Geprüft wird: `/board/data` liefert das Hauptboard mit Stationen und Probeprojekt; `/board/boards` zeigt keine Identität; Übernehmen antwortet 409 `fehlt:name`; `POST /board/identitaet` setzt den Namen; Übernehmen legt das eigene Board an; die Anzeige listet Hauptboard und eigenes Board; die README nennt „Hauptboard“, „Probeprojekt“ und den Token als optional.
- **Ergebnis:** neue README; vollständige `files`-Liste; `test/schritt39.mjs` grün.
- **Prüfung:** `cd /workspace/projekte/board-plugin && node --test test/schritt39.mjs` → `ok Frische Installation: Hauptboard ohne Einrichten, Name erst beim Beitreten, eigenes Board, README aktuell`. Danach `node --test` → 39 von 39; `node --check index.js`, `node --check client.js` → je 0.
- **Grenzen:** Produktordner und `/tmp/board-scheibe1/`; kein echtes frisches DSH-Profil und kein echter GitHub-Aufruf (die Prüfung bildet den Erststart in-process nach); keine Rückfrage; keine Commits; das echte Profil wird nicht angefasst.
