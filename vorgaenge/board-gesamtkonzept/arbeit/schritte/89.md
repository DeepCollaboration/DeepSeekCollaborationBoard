# Schritt 89 — Vorlagen und Startboard

- **Ziel:** Mit dem Plugin kommen fertige Vorlagen für ein öffentliches Board und ein Kanban. Eine Funktion legt daraus ein lokales Startboard an — echte Git-Repositories mit Commit und Tag, in der Board-Liste eingetragen, ohne Netz und ohne Anmeldung. Beim Start läuft sie noch nicht (das ist Schritt 91).

- **Eingang:** Produkt `/workspace/projekte/board-plugin`.
  - `formate/board.js`, `formate/workflow.js`, `formate/station.js`, `formate/hilfe.js` (Pflichtfelder und Prüfungen)
  - `boards.js` (Aufbau von `boards.json`, Anlegen und Committen, `verbindeBoard`)
  - `erststart.js` (wie heute das Hauptboard geholt und eingetragen wird)
  - `komposition.js` (`ortVon`, Auflösung von `workflows[].repo` und `stationen[].repo`)
  - `repos.js` (Ankerdatei, Git-Hilfen), `package.json` (`files`), `docs/entwicklung.md`
  - `test/schritt33.mjs` und `test/markt44.mjs` als Muster für ein frisches `DSH_HOME` ohne Netz

- **Tun:**

  1. **Vorlagen mitliefern.** Neuer Ordner `vorlagen/start/` im Paket, in `package.json` unter `files` aufgenommen:
     ```
     vorlagen/start/board-start/board.json
     vorlagen/start/workflow-oeffentlich/workflow.json
     vorlagen/start/workflow-kanban/workflow.json
     vorlagen/start/station-<slug>/station.json   (und je eine kurze README.md)
     ```
     Alle Dateien sind vollständig gültig und bestehen `liesBoard`/`liesWorkflow`/`liesStation` unverändert. Verweise stehen als Geschwisternamen: `board.json` → `workflow-oeffentlich`, `workflow.json` → `station-idee`, Fassung überall `v1` (der Tag wird beim Anlegen gesetzt).
     - **Öffentliches Board** (`id: oeffentlich`, Titel „Öffentliches Board“, `layout: auto`): fünf Stationen — Idee, Ausarbeitung, Umsetzung, Prüfung, Veröffentlichung. Je Station: sprechender `eingang`, `ausgabe`, `aktion: { art: 'textfeld' }`, `reife: 'entwurf'`, `lizenz: 'MIT'`, kurze `beschreibung`.
     - **Kanban** (`id: kanban`, Titel „Kanban“, `layout: auto`): vier Stationen — Idee, In Arbeit, Prüfung, Fertig, sonst gleiche Form. Das Schlagwort `kanban` kommt erst in Schritt 92; jetzt nicht eintragen.
     - Positionen: je Workflow eine Reihe im Raster (x in 400er-Schritten, y 0), Kanten als Kette in Stationsreihenfolge, `regeln: {}`.
     - `board-start/board.json`: `format: 2`, `id: 'start'`, `name: 'Mein Board'`, leere `vorgaenge`, Verweise auf die beiden Workflows.
     - Namen und Beschreibungen der Vorlagen sind **Inhalt**, keine Oberfläche: sie bleiben deutsch wie jede Station, die jemand anlegt. Keine Wörterbuchänderung.

  2. **Anlegen.** Neue Funktion `legeStartboardAn()` in `erststart.js` (exportiert):
     - Ziel `$DSH_HOME/board/start/`; darin je Repository ein Ordner: `board-start/`, `workflow-oeffentlich/`, `workflow-kanban/`, `station-<slug>/`.
     - Ist in `boards.json` schon ein Eintrag mit `id: 'start'`, gibt sie `{ angelegt: false }` zurück und ändert nichts. Sonst: Ordner aus `vorlagen/start/` kopieren (nur die Ankerdatei und README), je Ordner `git init -b main`, alles hinzufügen, commiten (feste Identität wie bei den vorhandenen Commits, z. B. über die bestehende Git-Hilfe), Tag `v1` setzen.
     - Danach `boards.json` schreiben: `format: 1`, Eintrag `{ id: 'start', name: 'Mein Board', format: 2, art: <was `verbindeBoard` für ein eigenes Board setzt>, repo: <absoluter Pfad zu board-start>, remote: null, person: null, sichtbarkeit: 'privat', angelegt: <ISO-Zeit> }`. `aktiv` nur setzen, wenn noch kein aktives Board eingetragen ist — ein vorhandenes aktives Board wird nie überschrieben. Andere Einträge bleiben unangetastet.
     - Kein Netz, keine Anmeldung, kein Push. Bricht das Anlegen ab, bleiben keine halben Einträge in `boards.json` (erst schreiben, wenn alle Repositories stehen).
     - Die Funktion liegt so, dass `apply` sie in Schritt 91 aufrufen kann; **in diesem Schritt ruft sie niemand auf**.

  3. **Dokumentation.** `docs/entwicklung.md`: kurzer Abschnitt „Startboard und Vorlagen“ — wo die Vorlagen liegen, dass Verweise Geschwisternamen sind und die Fassung `v1` ist, wie man eine Station ergänzt und dass das Startboard nur einmal angelegt wird.
