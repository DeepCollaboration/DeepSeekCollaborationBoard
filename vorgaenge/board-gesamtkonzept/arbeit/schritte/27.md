# Schritt 27 — Eine Station anlegen — mit austauschbarem Anlegeweg

- **Ziel:** Aus dem Board entsteht ein öffentliches Stations-Repository unter dem Eigentümer, mit Thema, `station.json` und README; der Anlegeweg ist eine Schnittstelle mit einem zweiten Platz.
- **Eingang:** Schritte 25, 26; `formate/station.js` (Pflichtfelder); `github.js` (`erstelleRepo` kennt bisher nur `/orgs/...`); `index.js` (`GET /board/station`, `cachePfad`, Board-Schreibwege); `komposition.js` (`ortVon`); `client.js` (Bibliothek); `test/markt26.mjs` (Prüffläche und `ctx`).
- **Tun:**
  1. **Route.** `POST /board/station` mit `{ name, beschreibung? }`; `GET` bleibt unverändert. Nur Fassung 2, sonst 409; ohne Board 409. `name` ist der Anzeigename, die Repo-Kennung `station-<slug>` (vorhandenes `slug`), 1–80 Zeichen, leer → 400. Ohne Eigentümer (Schritt 25 `leer`) → 403 mit Grund und Hinweis; ohne `anlegen.darf` (Schritt 26) → 403 mit dessen Grund.
  2. **Bauen, nicht schicken.** Im Zwischenspeicher `$DSH_HOME/board/cache/<owner>/<repo>`: Ordner anlegen, `station.json` (Format 2, Pflichtfelder: `id` = slug, `name`, `beschreibung`, `host` = Eigentümer, `eingang: []`, `ausgabe: []`, `aktion: { art: "textfeld", wert: beschreibung }`, `beispiele: []`, `reife: "entwurf"`, `lizenz: "nicht angegeben"`, `tags: []`), `README.md` (Name, Beschreibung, Thema); `git init -b main`, `add`, `commit`. Kein Token in `.git/config`, Argumenten oder URLs.
  3. **Die Naht.** Ein Anlegeweg ist eine Schnittstelle mit zwei Umsetzungen: `selbst` und `attrappe`. Die Wahl steht in `einstellungen.anlegeweg` (Vorgabe `selbst`); `attrappe` ist nur über die Einstellung erreichbar, nie in der Oberfläche. Die Schnittstelle umfasst **prüfen** (`frei?`) und **anlegen** (`{ owner, repo, beschreibung, themen, dateien } → { owner, repo, remote }`); Fehler tragen eine deutsche Meldung und einen Code.
     - `selbst`: prüft über `client.repo` (404 = frei, 200 = 409 „Eine Station mit diesem Namen gibt es schon“, anderer Fehler = 502); legt das öffentliche Repository an — ist der Eigentümer der angemeldete Login, `POST /user/repos`, sonst `POST /orgs/<owner>/repos` — setzt das Thema `dsh-board-station` und schreibt `station.json` und `README.md` über die Inhalts-API (`PUT /repos/<owner>/<repo>/contents/<pfad>`). Kein `git push`, kein Token in einer URL.
     - `attrappe`: prüft den Zwischenspeicher, schickt nichts, meldet Erfolg. Der nachgebildete GitHub-Server darf bei ihm **null** Aufrufe sehen.
  4. **Eintragen.** Nach Erfolg den Verweis `owner/repo` in `board.stationen` aufnehmen (nicht doppelt), `board.json` schreiben und einen Stand anlegen wie die übrigen Schreibwege. `komposition.js` löst `owner/repo` zusätzlich über `$DSH_HOME/board/cache/<owner>/<repo>` auf; die alte Form (nackter Name, Geschwisterordner) bleibt.
  5. **Antwort.** `POST` antwortet mit dem neuen Bild in der Form von `/board/data` plus `station: { owner, repo, pfad, name }`; die Seite übernimmt es ohne Neuladen.
  6. **Anzeige.** In der Bibliothek ein Knopf „Station anlegen“ (nur wenn `anlegen.darf`), darunter ein kleines Formular mit Name und Beschreibung, „Anlegen“ und „Abbrechen“; Fehler stehen im Formular. Keine Auswahl des Anlegewegs, kein „Torwächter“, kein „später“-Hinweis.
  7. **Prüfung.** `test/markt27.mjs`: Temp-Heim, Board mit `einstellungen: { eigentuemer: "testkonto", anlegeweg: "attrappe" }`, `DSH_GITHUB_API` auf einen geschlossenen Port. (a) Anlegen → lokales Repository unter `home/board/cache/testkonto/station-<slug>` mit gültigem `station.json` und README, Verweis in `board.json`, Karte in `/board/data`; (b) derselbe Name → 409, kein zweites Repository; (c) ohne Eigentümer → 403 mit Grund; (d) mit `anlegeweg: "selbst"` und nachgebildetem GitHub-Server: `/user/repos` (201), Thema, zwei Inhalte, Antwort 200; bei (a) null Aufrufe; (e) kein Token in `.git/config` des neuen Repositories.
     - **Live-Lauf, nicht Teil der Suite:** mit `BOARD_LIVE=1` und `BOARD_LIVE_TOKEN` (nur im Prozess, nie in einer Datei des Produkts) legt derselbe Test unter `ThomasTestDSBOARD` eine Station an, prüft Repository, Thema und Dateien über die API und löscht das Repository wieder. Ohne `BOARD_LIVE` kein echtes Netz.
  8. **README** (Produkt) um den Weg „Station anlegen“ ergänzen, drei Sätze.
- **Ergebnis:** Route, Naht mit zwei Anlegewegen, lokales Repository im Zwischenspeicher, GitHub-Anlage, Verweis und Karte; `test/markt27.mjs` grün.
