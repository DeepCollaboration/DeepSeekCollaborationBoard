# Schritt 30 — Dateien speichern

- **Ziel:** Eine Änderung an einer Datei eines Vorhabens landet in dessen Repository, nicht in der alten Ablage.
- **Eingang:** Schritt 29; `index.js` (`POST /board/doc/schreiben`, Zeile ~4000, liest bisher `liesBoard`); `dateiBasis`, `dateiName`, `ordnerVon`; `komposition.js` (`vorgaenge[].pfad`, `darf`); `test/markt29.mjs`.
- **Tun:**
  1. **Zweig für Fassung 2.** Vor `liesBoard()` prüfen: Ist das offene Board Fassung 2, den neuen Weg gehen; die alte Ablage bleibt unverändert.
  2. **Vorhaben auflösen.** Das Vorhaben über `koerper.vorhaben` (id) im zusammengesetzten Bild finden (`komponiere`); nicht gefunden → 404. Fehlt sein Ordner (`vorgang.pfad`) → 409 mit Grund.
  3. **Recht.** `vorgang.darf.aendern` (aus dem Bild) bzw. `darfSchreiben` auf den Ordner; ohne Recht → 403 mit Grund, kein Schreiben.
  4. **Pfad.** `koerper.datei` durch `dateiName` prüfen; zusätzlich: kein absoluter Pfad, kein `..`, kein Ausbruch aus dem Vorhaben-Ordner (aufgelöster Pfad muss mit dem Ordner beginnen) → sonst 400. Ordner statt Datei → 400.
  5. **Basis.** Die vorhandene Basisprüfung (`dateiBasis`, 409 mit `neu`) übernehmen, damit ein überholter Stand nichts überschreibt.
  6. **Schreiben und fassen.** Atomar schreiben (`tmp` + `rename`), dann im **Vorhaben-Repository** `git add -- <datei>` und `git commit` mit der handelnden Person als Autor; kein Commit im Board-Repository. Kein Push in diesem Schritt (das ist Schritt 39). Antwort wie bisher plus `basis` des neuen Standes.
  7. **Prüfung.** `test/markt30.mjs`: Temp-Heim, Board Fassung 2 mit einem Vorhaben-Repository (aus Schritt 29 oder von Hand gebaut). Geprüft wird: Schreiben → Datei nach erneutem Lesen geändert, `git log` im Vorhaben-Repository zeigt den Commit, das Board-Repository bekommt keinen; `..` und absoluter Pfad → 400; unbekannte id → 404; Vorhaben mit Remote ohne Token → 403; überholte Basis → 409 ohne Schreiben.
- **Ergebnis:** Schreiben landet im Vorhaben-Repository, mit Commit und Basisprüfung; alte Ablage unberührt; `test/markt30.mjs` grün.
- **Prüfung:** `cd /workspace/projekte/board-plugin && node --test test/markt30.mjs` → `ok Datei: im Vorhaben, Commit, Pfad abgewiesen, Basis`; danach `node --test` → 45 vorhandene plus der neue Test, 0 Fehler; `node --check index.js` → 0.
