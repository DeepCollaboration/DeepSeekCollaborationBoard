# Schritt 34 — Der Katalog führt zusammen

- **Ziel:** Der Katalog zeigt kuratierte und gefundene Dinge in einer Antwort, ohne Doppel, mit sichtbarer Herkunft.
- **Eingang:** Schritte 28, 31; `katalog.js` (`sammleKatalog`, `eintragLesen`); `formate/katalog.js`; `index.js` (`/board/katalog`); `test/markt28.mjs`.
- **Tun:**
  1. **Herkunft.** Jeder Eintrag trägt `herkunft`: `"kuratiert"` für Einträge aus `katalog.json`, `"gefunden"` für Suchtreffer. Die getrennten Listen `kuratiert` und `gefunden` bleiben.
  2. **Zusammenführen.** `eintraege` bleibt kuratiert zuerst, dann gefunden; je `owner/repo` einmal; ein kuratierter Eintrag bleibt unverändert (keine Felder der gefundenen Fassung).
  3. **Stand.** Die Antwort trägt `stand` (letzte Sammlung) und `standGefunden` (letzte Suche); ohne Netz gelten die letzten Stände mit Hinweis. `katalog.json` bleibt die Quelle der kuratierten; gefundene werden nicht hineingeschrieben.
  4. **Prüfung.** `test/markt34.mjs`: Temp-Heim, Hauptboard mit kuratierter Station (GitHub-Remote `kuratiert/station-y`), nachgebildeter Server mit `fremd/station-x` und dem Doppel `kuratiert/station-y`. Geprüft wird: `herkunft` an jedem Eintrag, `kuratiert`/`gefunden` getrennt, `eintraege` ohne Doppel mit kuratiert zuerst, `stand`/`standGefunden` gesetzt, `?suche=` filtert alle drei gleich, `katalog.json` bleibt unverändert. Kein echtes Netz.
- **Ergebnis:** Herkunft an jedem Eintrag, ein zusammengeführter Katalog mit zwei Ständen; `test/markt34.mjs` grün.
- **Prüfung:** `cd /workspace/projekte/board-plugin && node --test test/markt34.mjs` → `ok Katalog: Herkunft, eine Liste, zwei Stände, keine Doppel`; danach `node --test` → 49 vorhandene plus der neue Test, 0 Fehler; `node --check katalog.js`, `node --check index.js` → je 0.
