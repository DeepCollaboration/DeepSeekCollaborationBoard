# Schritt 66b — Der Grund im Lesemodus spricht die Sprache des Dashboards

- **Ziel:** Wer nur lesen darf, erfährt warum — in seiner Sprache. Heute steht
  dort der deutsche Satz des Hosts, auch wenn das Dashboard englisch ist.

- **Eingang:**
  - `/workspace/projekte/board-plugin/client.js` — `client.js:9760` und
    `client.js:9958–9959` zeigen `uebersetze(darfGrund)`; `darfGrund` kommt als
    deutscher Satz aus der Antwort von `/board/data`.
  - `/workspace/projekte/board-plugin/rechte.js` — die fünf Sätze, die als
    `grund` entstehen können: `GRUND_OHNE_TOKEN`, `GRUND_OHNE_RECHT`,
    `GRUND_NICHT_PRUEFBAR`, `GRUND_ANMELDUNG_UNGUELTIG` und der Rückfall
    `'Kein Schreibrecht für dieses Board.'`.
  - `/workspace/projekte/board-plugin/test/markt48.mjs` — die Prüfung, die
    verlangt, dass jeder Wörterbuchschlüssel im Client als Zeichenkette steht.

- **Tun:**
  1. Im Client eine Tabelle anlegen, die die fünf deutschen Sätze auf ihren
     übersetzten Text abbildet — jeder Satz steht dabei **als Zeichenkette** im
     Client, damit `test/markt48.mjs` ihn sieht:
     ```js
     const GRUND_TEXTE = {
       'Keine Anmeldung: es fehlt ein Token.': uebersetze('Keine Anmeldung: es fehlt ein Token.'),
       …
     };
     ```
  2. An den drei Stellen nicht mehr `uebersetze(darfGrund)` rufen, sondern
     `GRUND_TEXTE[darfGrund] || uebersetze('Für dieses Board fehlt das Schreibrecht.')`.
     Ein unbekannter Satz fällt auf den vorhandenen Satz zurück — nie auf
     Deutsch, wenn die Sprache eine andere ist.
  3. Die fünf Sätze in alle sieben Wörterbücher; `de.json` bleibt leer.
  4. `index.js` bleibt unberührt: der Host schickt weiter seinen deutschen Satz.

- **Ergebnis:** `client.js` mit der Tabelle; `texte/*.json` mit fünf Schlüsseln;
  `test/nach66b.mjs`.

- **Prüfung:**
  - `cd /workspace/projekte/board-plugin && node --check client.js && node --test test/*.mjs`
  - `test/nach66b.mjs`:
    1. die fünf Sätze stehen als Zeichenketten im Client und in allen sieben
       Wörterbüchern;
    2. die drei Stellen rufen nicht mehr `uebersetze(darfGrund)`, sondern die
       Tabelle mit Rückfall;
    3. ein unbekannter Grund ergibt den vorhandenen Satz, nicht den rohen Text;
    4. Suite grün, `test/markt48.mjs` grün (keine überzähligen Schlüssel).

- **Grenzen:** Nur `client.js`, `texte/*.json` und `test/nach66b.mjs`.
  `index.js` und `rechte.js` bleiben unberührt. Keine Rückfrage.

Am Ende: Bericht nach `arbeit/schritte/66b-bericht.md` — die fünf Sätze, die drei
Stellen, welcher Befehl, welcher Exit-Code.
