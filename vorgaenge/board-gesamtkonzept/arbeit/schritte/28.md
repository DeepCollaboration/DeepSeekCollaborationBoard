# Schritt 28 — Auffinden

- **Ziel:** Öffentliche Stationen anderer erscheinen ohne Zutun, neben den kuratierten; doppelte werden zusammengeführt.
- **Eingang:** Schritt 27; `katalog.js` (`sammleKatalog`, `katalogCachePfad`, `liesKatalogCache`); `github.js` (Suche fehlt); `index.js` (`/board/katalog`); `formate/katalog.js`; `test/markt26.mjs` (nachgebildeter Server).
- **Tun:**
  1. **Suche.** In `github.js` eine Suche nach Thema: `GET /search/repositories?q=topic:dsh-board-station&sort=stars&per_page=50`. Ohne Token erlaubt (anonym), mit Token besser; Rückgabe je Treffer `{ owner, name, beschreibung, sterne, web, themen, archiviert }`. Ein Fehler (Rate, Netz) ist eine Meldung, kein Absturz.
  2. **Gefunden.** In `katalog.js` nach den kuratierten Einträgen die Suche ausführen; jeder Treffer wird ein Eintrag `{ art: "station", repo: "owner/name", name, beschreibung, sterne, web, herkunft: "gefunden", github: { owner, name } }`. Archivierte überspringen. Ein Treffer, dessen `owner/name` schon kuratiert ist, wird nicht doppelt aufgenommen; innerhalb der Gefundenen wird über `owner/name` (ohne Rücksicht auf Groß-/Kleinschreibung) zusammengefasst.
  3. **Zwischenspeicher.** Der Katalog-Zwischenspeicher trägt zusätzlich `gefunden: { am, eintraege }`; Haltbarkeit wie bisher (10 Minuten). Ohne Netz oder bei einem Fehler der Suche gilt der letzte Stand, `hinweis` nennt ihn („Ohne Verbindung: letzter Stand vom …“). `frisch=1` erzwingt die Suche. Ein leerer Treffer ist kein Fehler.
  4. **Antwort.** `/board/katalog` antwortet zusätzlich mit `kuratiert` (nur die kuratierten) und `gefunden` (nur die gefundenen); `eintraege` bleibt die zusammengeführte Liste, kuratiert zuerst, ohne Doppel. Die Suche (`?suche=`) wirkt auf alle drei Listen gleich.
  5. **Keine Anzeige-Änderung in diesem Schritt** — die Bibliothek und das Vertrauensbild folgen in Schritt 34/37.
  6. **Prüfung.** `test/markt28.mjs`: Temp-Heim, Hauptboard mit einer kuratierten Station, die einen GitHub-Remote `kuratiert/station-y` trägt; nachgebildeter Server liefert zwei Treffer: `fremd/station-x` (neu) und `kuratiert/station-y` (Doppel). Geprüft wird: `gefunden` enthält nur `fremd/station-x`; `kuratiert` enthält die kuratierte; `eintraege` enthält beide je einmal; ein zweiter Aufruf innerhalb der Haltbarkeit fragt den Server nicht erneut; nach Schließen des Servers mit vorhandenem Zwischenspeicher kommen der letzte Stand und ein Hinweis; `frisch=1` fragt erneut. Kein echtes Netz.
- **Ergebnis:** Katalog mit `kuratiert` und `gefunden`, Doppel zusammengefasst, letzter Stand ohne Netz; `test/markt28.mjs` grün.
